# HerHealth 🌸
### Track. Understand. Take Charge.

HerHealth is a menstrual health tracking and awareness web application that helps users record their periods, track daily symptoms, and understand their health information.

## ✨ Features
- **Period Tracker:** Record period start and end dates.
- **Daily Symptoms:** Log symptoms and their intensity.
- **Health Dashboard:** View summaries based on recorded information.
- **Consultation Report:** Organize health records and questions for a healthcare professional.
- **Tips:** Explore menstrual health awareness information.
- **User Accounts:** Create an account or log in to access data-entry features.
- **Profile and Settings:** Manage profile details and preferences.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Python
- FastAPI
- SQLite
- SQLAlchemy

## 🚀 How to Run

### 1. Start the backend

Open a terminal in VS Code and navigate to the folder containing `main.py`.

Install the dependencies:

```bash
pip install -r requirements.txt
```

Start the FastAPI server:

```bash
python -m uvicorn main:app --reload
```

The backend runs at:

`http://127.0.0.1:8000`

To view the API documentation, open:

`http://127.0.0.1:8000/docs`

### 2. Open the frontend

Open `app1.html` in your browser, or use the VS Code Live Server extension if your project is configured for it.

Keep the backend running while testing features that use the API.

## 🔒 Privacy and Health Disclaimer

Your data is safe and secure with us.

HerHealth supports tracking and educational awareness on menstrual health. It doesn't replace professional medical advice.

HerHealth is an awareness and tracking tool, **not a diagnostic application**.
